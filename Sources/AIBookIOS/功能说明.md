# AIBookIOS

iPhone 和 iPad 的界面壳。一次只铺一页。底栏常驻原文、讲解、翻译、阅读；沉浸阅读时底栏隐藏。右上角「更多」为 book 设置、说明书、隐私、保存 `.aibook`；页内 ⋯ 仍是本页操作。界面语言、八套风格预设、阅读字体与字号与 Mac 共用 `UserDefaults` 键；设置页分 AI、朗读、外观三栏，说明书与隐私按当前语言显示正文，不再用占位文案。

## 不做什么

不改 Mac 的窗口、皮革顶栏、书脊和阅读模式。不在这里做进化或 Cursor。

## 典型入口

`AIBookIOSApp.swift`、`IOSRootView.swift`、`IOSBubbleMenu.swift`、`IOSShellModel.swift`、`IOSReadingService.swift`

与 Mac 共用代码通过 `AIBookIOS.xcodeproj` 的 Shared 组显式编入；`BookStyleTokens` 用 `#if canImport(UIKit)` / `AppKit` 分支，避免 iOS 拉进桌面专属 API。AI 请求默认 **SSE 流式**（`aiBook.ios.streamResponses`），讲解/译文 `TextEditor` 随生成刷新。

DEBUG 启动参数 `-SnapshotTranslationCompare` 会注入静夜思样例并打开翻译对照，供 `AIBookIOSUITests` 与模拟器截图（`docs/UI/snapshots/ios-translation-compare.png`）。左缘 `IOSBubbleMenu` 仅是墨色 ⋯ 换页菜单，不再做半圆拉开动画。

桌面图标用 Mac 版同一张书封图，放在 `Assets.xcassets/AppIcon`。用 Xcode 打开仓库根目录的 `AIBookIOS.xcodeproj`，选 iPhone 或 iPad 模拟器运行。讲解、翻译、原文补充走设置里的 OpenAI 兼容接口。按住麦克风用本地口令。各页标题旁的菜单对应 Mac 的文档、讲解、翻译和朗读菜单。原文页空白时也能直接打字，编辑器铺满纸面。打包时 `scripts/copy-ios-seed-books.sh` 把仓库 `book/` 各子文件夹里的 txt 和 `.aibook` 放进安装包的 `SeedBooks`。安装后第一次进入会把这些书按原文件夹拷进文稿，并默认打开排序后的第一本 `.aibook`（没有包时打开第一份文本）。文稿里已有的同名文件不会被盖掉。打开文件先列出这些文件夹和文本，点进文件夹再选书；取消能回到原文，右上角仍可交给系统选择器。包里没有种子书时，仍放一份静夜思。打开目录只选文件夹。原文补充按 Mac 的名著补充，只把标记里的正文写回；有选区时只替换选区。设置里点 DeepSeek 会填上 `https://api.deepseek.com/v1` 和 `deepseek-chat`，再填密钥即可补充、讲解和翻译。

## 中文注释（强制）

按 [规约 §4.1](../../docs/规约/方便人理解代码规约.md#41-强制每个类型每个方法每行行尾中文)：**每个类型 / 方法有 `///`；每一行可执行代码有行尾 `//` 中文**。本轮已补齐 `IOSAlignmentSync`、`IOSLayout`、`IOSDirectoryBookmark`、`IOSLLMErrorMessage`、`IOSKeyboardNotifications`、`PrivacyPolicy`（`IOSPrivacyPolicy.swift`）及 `IOSChatClient` 流式循环等；其余 Swift 文件随改动逐步补。可用 `scripts/add_swift_trailing_line_comments.py` 生成初稿后人工润色。

**设置**：讲解/译文流式开关文案键 `ios.settings.streamResponses`（设置 → AI）。
