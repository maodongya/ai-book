# AIBook

macOS 辅助读书应用包：启动、读书双页、设置、LLM / Cursor / 语音，以及应用内进化编排。

## 不做什么

不把可纯测的进化分析、优化队列算法写在 View 里；那些属于 `AIBookEvolution`。

## 典型入口

`App/AIBookApp.swift`

## 子目录

| 目录 | 说明 |
|------|------|
| [App](App/功能说明.md) | 进程入口与全局设置 |
| [Core](Core/功能说明.md) | 跨能力领域类型与文案 |
| [Reading](Reading/功能说明.md) | 左页阅读与右页讲解编排 |
| [UI](UI/功能说明.md) | 壳层控件与设置 |
| [LLM](LLM/功能说明.md) | 大模型连接与配置 |
| [Cursor](Cursor/功能说明.md) | Cursor Agent 桥接 |
| [Speech](Speech/功能说明.md) | 朗读与音色 |
| [Evolution](Evolution/功能说明.md) | 应用内进化编排 |
| [Persistence](Persistence/功能说明.md) | 会话与密钥等读写 |
| [Resources](Resources/功能说明.md) | 随包资源 |

## 依赖

可依赖 `Core`、`Persistence`、`AIBookEvolution`。领域与进化库不得反向依赖本包的 `App` / `UI` / `Reading`。
