# AIBook 機能説明書

> **AIBook**（プロジェクト識別子 `ai-book`）は macOS ネイティブの読書補助アプリです。**左ページ**でローカルのテキストを読み、編集し、**右ページ**で AI による解説、翻訳、読み上げ、そして（任意で）アプリ自身の更新を行います。  
> **対応システム**：macOS 13 以降。  
> **位置づけ**：字面、文脈、対訳、没入して読むことを助ける道具です。電子書籍リーダーそのものではありません。

アプリ内の説明書は界面言語に従います。このファイルは日本語版です。簡体字中国語は `功能说明书.md`、ほかの言語は同じフォルダの `功能说明书-en.md`、`功能说明书-de.md`、`功能说明书-fr.md`、`功能说明书-it.md`、`功能说明书-la.md`、`功能说明书-el.md` です。編集したら、同じ名前のファイルを `Sources/AIBook/Resources/` に同期してからパッケージしてください。

---

## アプリ内での開き方

- メニューバー **ヘルプ → AIBook 機能説明書**（アプリ内ウィンドウ。文字を選択してコピーできます）
- **ヘルプ → Finderで説明書を表示**（現在の言語の説明書ファイルを Finder で選択します）
- 説明書ウィンドウのタイトルバー **デフォルトアプリで開く**
- **book 設定** と **進化設定** のタイトルバーにある **説明書** ボタン

## 1. 製品の概要

### 1.1 できること

- 左ページでローカルの `.txt` を読み、編集する。
- 選択範囲または全文の解説を依頼し、同じ会話で追問する。
- 逐語訳または段落訳を作り、原文と訳文の対照表を見る。
- 原文、翻訳、解説を読み上げる。
- 読書モードに入り、見開きの本のようにページをめくる。
- 任意で AI 進化を使い、プロジェクトを分析し、待ち行列の一件を適用してアプリを再構築する。

### 1.2 机のたとえ

ウィンドウは机です。左ページが原文、右ページが助手です。読書モードでは助手を隠し、めくれる本だけを見せます。

### 1.3 二つの最上位モード

| モード | 用途 |
|--------|------|
| **学習モード** | 左が原文、右が解説・翻訳・読み上げ |
| **読書モード** | 没入してページをめくる。解説と翻訳は学習モードに戻ってから |

タイトルバーの **読書モード**（⌘⇧P）と **学習モード** で切り替えます。

## 2. メインウィンドウ（学習モード）

タイトルバーには原稿、解説、翻訳、読み上げ、レイアウト、設定があります。左ページが原文です。右ページは読書アシスタントで、そのタブを選ぶと **AI 進化** になります。

### 2.1 レイアウト

| レイアウト | 意味 |
|------------|------|
| **見開き** | 左ページと右ページを並べる |
| **原文を全画面** | ⌘⌥2。原文が机を占める |
| **右全画面** | ⌘⌥3。助手が机を占める |

集中表示から **Esc** で見開きに戻ります。

### 2.2 読書アシスタントの中の欄

| 欄 | 内容 |
|----|------|
| **解説結果** | 複数ターンの対話、ストリーム出力、保存 / 開く / 消去 |
| **翻訳結果** | 翻訳 JSON または対照表。編集、整列、固定ができる |

タイトルバーの **解説** / **翻訳** カプセルで欄を切り替えます。翻訳の操作を実行すると翻訳欄に移ります。

### 2.3 集中

解説欄と翻訳欄はツールバーと入力を隠し、本文だけを残せます。戻すボタンは **集中読書**、**ツールバーを表示**、**入力を表示** です。

## 3. 読書モード

### 3.1 入る、出る

| 操作 | 方法 |
|------|------|
| 入る | タイトルバー **読書モード**、ショートカット **⌘⇧P**（空でない原文が開いていること） |
| 出る | **読書モードを終了**、または **Esc** |

読書モードでは解説も翻訳もしません。AI が必要なときは学習モードに戻ってください。

### 3.2 レイアウト

| 項目 | 意味 |
|------|------|
| **見開き** | 左が第 N ページ、右が第 N+1 ページ。**背表紙は固定** |
| **全画面** | 1 ページがウィンドウを占める |
| 切り替え | 読書用タイトルバーの **見開き / 全画面**、または **⌘⌥1 / ⌘⌥2** |

### 3.3 ページのめくり方

| 方法 | 動き |
|------|------|
| **← / →** | 前の見開き / 次の見開き |
| **左ページ / 右ページをクリック** | 見開きでは進む / 戻る |
| **水平にドラッグ** | 指に追従する。およそ三分の一を超えて離すとめくり切り、それ以外は戻る |
| **タイトルバーの矢印** | キーボードと同じ |

アニメーションは **紙を一枚** めくります。背表紙は変形しません。

### 3.4 ページ割りと進捗

- ページ割りは左ページと同じ **文字サイズ、フォント、行間、余白**（**book 設定 → 外観**）を使います。
- ウィンドウサイズや組版が変わると **割り直し**、今の位置をできるだけ保ちます。
- ファイルごとに **見開きの番号** を保存し、次に読書モードへ入ったとき復元します。
- フッターは **3–4 / 128 ページ**（見開き）または **N / M ページ**（全画面）のように表示します。

## 4. 原稿とファイル

### 4.1 対応する原稿

- 主な形式は **UTF-8 のプレーンテキスト `.txt`** です。
- 左ページは **自由に編集** できます。選択、コピー、ファイルのドラッグオープンができます。

### 4.2 ファイルメニューと原文の操作

| 機能 | ショートカット | 説明 |
|------|----------------|------|
| **原文を新規作成** | ⌘N | 左ページを空にして新しい原稿にする |
| **原文を開く…** | ⌘O | ローカルの `.txt`。ツールバーは **原文を開く** |
| **原文のフォルダを開く…** | | 4.4。ツールバーは **原文のフォルダを開く** |
| **原文を保存** | ⌘S | 現在のパスへ保存 |
| **原文を別名で保存…** | ⌘⇧S | 左ページ全文を新しいファイルにする |
| **原文を AIBook として保存…** | | 原文と既存の訳・解説を一つの `.aibook` に |
| **原文の選択を書き出し…** | ⌘⌥S | 左ページの現在の選択だけ |
| **原文をすべて選択** | ⌘⌃A | |
| **原文を補完** | ⌘⇧C | 第 9 節 |

外部ファイルを開いていないとき、左ページは **コマンドノート** を読み込みます（4.3）。

### 4.3 コマンドノート（既定の左ページ）

- 初回、またはファイルを開いていないとき、左ページはメモ用のコマンドノートです。
- 保存先は `~/Library/Application Support/AIBook/readme-notes.txt` です。
- ローカルの副本がなければ、アプリ内蔵またはプロジェクトの `readme.txt` ひな形に戻ります。
- **⌘S** でコマンドノートを Application Support に保存します。

> 現在の **最適化キュー** は `optimization-queue.json` です。コマンドノートは進化の実行時コマンド源ではなく、個人のメモとして使えます。

### 4.4 フォルダ一覧（書庫）

**入口**：**原文のフォルダを開く…**。ウィンドウの題は **フォルダ**。サイドバーは **開いているフォルダ**。

| 手順 | 説明 |
|------|------|
| フォルダを追加 | サイドバーの **+** で書籍のルートを選ぶ |
| フォルダを切り替え | 「開いているフォルダ」で選ぶ |
| ファイルを見る | 中央のツリーでサブフォルダを開く |
| 開き先 | **左ページの原文エリアで開く**、**右ページの翻訳エリアで開く**、**右ページの解説エリアで開く** |
| 開く | ダブルクリック、または下部で確定 |

追加したフォルダと展開状態は **保存** され、次回起動でも使えます。同じ書庫の `.txt`、`-翻訳.txt`、解説稿を行き来するのに向いています。

## 5. AI のバックエンドと設定

解説、翻訳、**原文を補完** は **book 設定** の読書用モデルを使います。AI 進化は Cursor 固定で、**進化設定** にあります。タイトルバーに切り替えはありません。

### 5.1 読書はモデル、進化は Cursor

| 用途 | 入口 |
|------|------|
| 解説、翻訳、原文を補完 | **book 設定** → **AIモデル** → **現在のプロバイダ** |
| **分析**、**進化** | **進化設定** の **Cursor モデル** |

タイトルバーのカプセルはファイル名と **未保存**。未設定のカプセルは **book 未設定**。Cursor が使えないときは **Cursor 未準備**。

### 5.2 book 設定

**入口**：タイトルバーの **book 設定**。

#### AI モデル

- **提供者ごと** に API アドレス、キー、既定モデルを保存します。
- 内蔵の例：

| 提供者 | 典型的な用途 |
|--------|--------------|
| OpenAI | クラウドの GPT 系列 |
| DeepSeek | 費用を抑えた中国語 |
| Ollama | **この Mac で無料**（日常の読書に推奨） |
| Moonshot / 通義 / 智譜 | 中国国内のクラウド |
| カスタム | 任意の OpenAI 互換端点 |

**Ollama の始め方**：

```bash
ollama serve
ollama pull llama3.2
```

book 設定で Ollama を選び、**この Mac に入っているモデルを走査** して使います。Ollama が API キーを要求するときは、設定に記入してください。

- **翻訳先の言語** と **解説の言語**：簡体字中国語、英語、日本語、ドイツ語、フランス語、イタリア語、ラテン語、ギリシャ語を複数選べます。次の生成はチェックした順に出します。すでにある結果は右ページで切り替えられ、`.aibook` を保存すると一緒に残ります。
- **左ページ抜粋比率**：各リクエストに載せる左ページ原文の割合です。モデルの窓を超えないようにします。

#### 音声

第 8 節を見てください。

#### 外観

第 11 節を見てください。

### 5.3 進化設定

**入口**：メニュー **AIBook → 設定**（進化タブ）。

| 項目 | 説明 |
|------|------|
| Cursor API キー | または環境変数 `CURSOR_API_KEY` |
| Cursor モデル | Composer 系列など |
| cursor-bridge のパス | プロジェクト内の `cursor-bridge` |
| 自動アップグレード | **進化** を一度押したあと、キューに残りがあれば続けて実行できる（第 10 節） |

**Cursor ローカルの依存**：

```bash
cd ai-book/cursor-bridge
npm install
```

**Node.js 18 以降** が必要です。

## 6. 解説

### 6.1 基本の流れ

1. 左ページで一節を **選択** する。選択しない場合は全文を文脈にします。
2. **選択部分を解説**（⌘R）または **全文を解説**（⌘⇧R）、あるいはタイトルバーの解説メニューを使います。
3. AI は解説言語ごとに右ページの「解説結果」へ出力します。複数言語のときは、シートの題に言語名と番号が付きます。
4. 終わると、最後に成功した言語を **自動で読み上げ** できます（途中で止められます。音声は第 8 節）。

解説本文は選んだ言語で書かれます。目標が簡体字中国語のとき、古文は現代の書き言葉で説明します。右ページは一度に一言語です。ツールバーの「解説を表示」と解説メニューは、すでにできた解説を切り替え、モデルを呼び直しません。`.aibook` を開く、または保存すると各言語が残ります。解説 `.txt` を開くと、今見ている言語だけに書き込みます。新規と消去は今の一言語だけを除きます。

### 6.2 追問

- 右ページ下部の **入力欄** で続けて質問できます。AI は現在のファイルとこれまでの対話を使います。
- 同じ本の対話は、再起動後もファイルパスに結びつけて **できるだけ復元** します。

### 6.3 解説稿の管理

| 操作 | 説明 |
|------|------|
| 新規 | 今見ている言語の解説だけを空にする。ほかの言語は包に残る |
| 開く | `.txt` の解説稿を、今見ている言語へ読み込む |
| 保存 | 現在の解説を UTF-8 テキストで保存する |
| すべて選択 | 解説欄の文字をすべて選ぶ |
| 解説を消去 | 今の言語の解説を削除する |
| 解説を読み上げ | 解説全文を読む、または止める |

### 6.4 メッセージ一件

吹き出しを **右クリック** すると、コピー、削除、または **その AI の返答だけ** の読み上げができます（メニューは現在の版に従います）。

### 6.5 選択範囲との関係

タイトルバーのボタンを押すと、左ページの強調がいったん消えることがあります。アプリは **直前の空でない選択を覚えておく** ので、「選択部分を解説」は先ほど選んだ文字に対して行われます。

## 7. 翻訳

### 7.1 二つの翻訳モード

| モード | 入口 | 出力 |
|--------|------|------|
| **逐語訳** | 翻訳メニュー → 逐語訳 | 原文の順に字や語を分け、短い説明を付ける。精読向け |
| **段落訳** | 翻訳メニュー → 段落訳 | 段落の形を保った通読できる訳。章を読むのに向く |

**翻訳する原文**：左ページの **現在の選択** を優先し、選択がなければ左ページの **全文** です。

**翻訳先の言語**：**book 設定 → AI モデル → 翻訳先の言語** で複数選べます。**翻訳メニュー** のチェックでも選べます。生成はその順です。右ページは一度に一言語で、すでにある訳は **翻訳を表示** で切り替えます。`.aibook` には各言語が一緒に残ります。中国の古文を簡体字中国語へ訳すときは、現代の書き言葉になります。

結果は整列ブロックを含む構造化 **JSON** として翻訳欄に出ます。テキストも表も **直接編集** できます。

### 7.2 翻訳ファイル

| 操作 | 説明 |
|------|------|
| 翻訳を開く | 既存の翻訳 JSON またはテキストを読み込む |
| 翻訳を保存 | よくある名前は `元のファイル名-翻訳.txt` |
| 翻訳を消去 | 現在の翻訳と整列を削除する |
| 翻訳をすべて選択 | ⌘⌃⇧A |
| 翻訳を読み上げ | ⌘⌥T、または翻訳ツールバーの「読み上げ」 |

### 7.3 対照表と整列

翻訳 JSON に有効な **整列ブロック**（字、語、段落）があるとき：

| 機能 | 説明 |
|------|------|
| **翻訳対照** | 右ページを **原文と訳文の対照表** にする |
| **翻訳を揃える** | 左ページが変わったあと、訳文との対応を計算し直す |
| **翻訳を固定** | 全体の再整列を誤って押さないようにする。一行の編集は通常まだできる |
| **翻訳の固定を解除** | 全体の再整列を再び許す |

左ページの変更が大きいと、ツールバーの文は **整列が無効です。「翻訳を揃える」または「解説を揃える」をタップして復元** です。解説側のボタンは **解説対照**、**解説を揃える**、**解説を固定**、**解説の固定を解除** です。

### 7.4 左ページのスクロールとの連動

学習モードの **見開き** で **翻訳対照** がオンかつ整列が有効なとき、左ページをスクロールすると対照表の対応する行を **強調** できます。細部は現在の版に従います。

## 8. 音声読み上げ

### 8.1 入口

| 対象 | よく使う入口 |
|------|----------------|
| 左ページの選択 | 読み上げメニュー → 原文の選択を読む。⌘⌥R（選択か全文かはメニューの定義） |
| 左ページ全文 | 読み上げメニュー → 原文全文を読む |
| 翻訳 | ⌘⌥T、翻訳ツールバー、翻訳メニュー |
| 解説 | 解説メニュー → 解説を読み上げ。メッセージの右クリック |
| 試聴 | book 設定 → 音声 → 現在の声を試聴 |

### 8.2 タイトルバーの再生制御

読み上げ中、タイトルバー中央に **一時停止 / 再開 / 停止** が出ます。今流れている解説または原文に対して働き、サブメニューは不要です。

### 8.3 ペース（book 設定 → 音声）

分段コントロールの題は **ペース**。日本語界面でも、選択肢はこの四つの文字です。下に出る文もそのままです。

| 選択肢 | コントロール下の文 | 意味 |
|--------|--------------------|------|
| **快速** | 快速：速いペース。 | 速く聞く |
| **平衡** | 平衡：標準的なペース。 | 標準。既定になりやすい |
| **自然** | 自然：聞き取りやすい。 | 聞き取りやすくする |
| **舒缓** | 舒缓：ゆっくり。 | ゆっくり読む |

### 8.4 言語処理

題は **言語処理**。選択肢は **高效**、**平衡**、**深度**。下の文は「言語処理・高效」「言語処理・平衡」「言語処理・深度」です。意味は、書き換えを少なく速くする、速度と明瞭さの中間、短い文と句読点の間、です。

### 8.5 解説の声

- **システムの中国語音声**：macOS 内蔵の中国語の声。
- **オンラインのニューラル女声**（Edge TTS）：暁伊、暁暁、各地の女声。
- オンラインの声は、設定で **見本をダウンロード** してローカルに置いてから安定して使えます。

再生前に Markdown などを **清書し、文に分けます**。

### 8.6 音声操作

タイトルバーのマイクを **押している間話し、離すと実行** します。読書モードでそのボタンが無いときは、アプリが前面にあるあいだ **Option+スペースを押し続け** ます。音声を文字にし、翻訳・解説と同じ読書用モデルで既存の機能に対応づけます。解説、翻訳、読み上げ、レイアウト、開く、保存、書き出しなどはすぐ実行します。進化の開始と最適化の分析は先に確認します。聞き取れない、またはどの機能にも合わないときは実行せず、聞こえた文字だけを表示します。

## 9. 原文を補完

| 項目 | 説明 |
|------|------|
| 入口 | タイトルバーの **原文を補完**、原文メニュー、⌘⇧C |
| 入力 | 左ページの抜粋（選択または全文） |
| 動き | AI が名作を判別し、**続く一続きの章として補う**。原著の文体をできるだけ保つ |
| 出力 | **左ページ** に書き戻し（選択または全文を置換）、可能なら **自動保存** |

教材の抜粋や断片から、読める文脈を戻すための機能です。権利のない複製には使わないでください。ご自身が使う権利のあるテキストだけで使ってください。

## 10. AI 進化（高度な機能）

> **警告**：進化は AIBook のソースを変更し、アプリを再インストールします。Git とバックアップが分かるときに使い、大切な環境で自動アップグレードをむやみに開かないでください。

### 10.1 何をするか

- **分析して最適化**：AI はプロジェクトを **読むだけ** で、改善案を **最適化キュー** に書きます。コードは変えません。
- **進化**：キューから **未処理** を一件取り、AI が **コードを変え**、ビルドしてインストールし、**アプリを再起動** します。

### 10.2 典型的な手順

1. 右ページの **AI 進化** タブを開く。
2. **分析** を押し、提案がキューに入るのを待つ。
3. キューの項目（題、番号、状態）を見る。
4. タイトルバーの **進化**（メニューでは **自己進化**、⌘E）で次の未処理を実行する。
5. **思考** と **ツール手順** の時系列を見る。
6. 終わるとアプリが再起動することがあります。**自動アップグレード** がオンで、このセッションですでに進化を手動で始めた場合、続く未処理が **連続して実行** されることがあります。

### 10.3 進化コマンドとキューファイル

- キューファイル：`~/Library/Application Support/AIBook/optimization-queue.json`
- 進化タブでは進化コマンドの原稿（UTF-8）を **保存 / 開く** ことができます。
- 分析で入れるとき、正規化した題で **重複を除きます**。一回の分析の提案数には上限があります（およそ 8 件）。

### 10.4 実行経路

**分析** と **進化** はどちらも Cursor のローカルエージェントです。読書用モデルへ戻すスイッチはありません。分析は読むだけです。**進化** がコードを変え、ビルドしてインストールします。Cursor が未準備だとボタンは使えず、カプセルは **Cursor 未準備** です。

### 10.5 トークンと状態

- 進化と長い対話は **トークン予算** の中です。画面に使用量が出て、上限を超えると送信できません。
- タイトルバーのカプセルは **未処理の件数** や次の番号を出せます。

## 16. おすすめの使い方

### 16.1 日常の読書と質問

1. ⌘O で章の `.txt` を開く。
2. 分からない段落を選び、⌘R で解説する。
3. 下部の入力欄で追問する。
4. 読書に集中するときは ⌘⇧P で読書モードへ入る。

### 16.2 外国語、または古典の精読

1. 左ページに原文を載せる。
2. **段落訳** または **逐語訳** を実行する。
3. **翻訳対照** をオンにし、安定した版を **固定** する。
4. ⌘⌥T で訳文、⌘⌥R で原文を読み上げて比べる。

### 16.3 複数ファイルの書庫

1. **ファイル → フォルダを開く…** で書庫のルートを追加する。
2. ツリーで `chapter-01.txt` を **原文** として開く。
3. `chapter-01-翻訳.txt` を **翻訳** として開く。
4. 同じウィンドウで解説欄と翻訳欄を切り替える。

### 16.4 抜粋の補完

1. 左ページに教材の抜粋を貼る。
2. ⌘⇧C で原文を補完する。
3. 結果を確認して ⌘S で保存する。

## 17. よくある質問

**解説を押すと、大模型が未設定だと出る。**  
**book 設定 → AI モデル** を開き、提供者を選んで API キーを記入してください。この Mac では Ollama がおすすめです。

**Cursor ローカルが使えない。**  
Node.js、cursor-bridge の `npm install`、Cursor API キー、進化設定のパスを確認してください。

**翻訳の対照表が灰色。**  
先に逐語訳または段落訳を終え、JSON に有効な整列ブロックがある必要があります。失効しているときは **翻訳を揃える** を使います。

**読書モードのページ番号が変わった。**  
文字サイズやウィンドウを変えると割り直します。正常です。見開きの位置はできるだけ復元します。

**進化のあと、アプリの動きが変わった。**  
進化が変えるのは、ローカルにインストールされた AIBook です。ソースは Git で管理し、自動アップグレードは慎重に使ってください。

**説明書と界面が一致しない。**  
インストールした **AIBook の版** を優先してください。ボタンにポインタを置くと最新のヒントが出ます。
