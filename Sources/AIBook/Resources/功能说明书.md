# AIBook 功能说明书

> **AIBook**（项目标识 `ai-book`）是 macOS 原生辅助读书应用：**左页**阅读与编辑本地文本，**右页**通过 AI 完成讲解、翻译、朗读与（可选）应用自我升级。  
> **适用系统**：macOS 13 及以上。  
> **产品定位**：辅助读书——帮助理解字面含义、上下文、译文对照与沉浸阅读，而不是替代完整电子书阅读器。

应用内说明书随界面语言切换：简体中文读本文件，其它语言读同目录的 `功能说明书-en.md`、`功能说明书-ja.md`、`功能说明书-de.md`、`功能说明书-fr.md`、`功能说明书-it.md`、`功能说明书-la.md`、`功能说明书-el.md`。修改后请把同名文件同步到 `Sources/AIBook/Resources/`，以便重新打包。

---

## 在应用内如何打开

- 菜单栏 **帮助 → AIBook 功能说明书**（应用内窗口，可选中复制文字）
- **帮助 → 在访达中显示说明书**（在访达中选中当前语言的说明书文件）
- 说明书窗口顶栏 **用系统应用打开**
- **book 设置** 与 **进化设置** 顶栏的 **说明书** 按钮

## 1. 产品概述

### 1.1 您可以用 AIBook 做什么

| 能力 | 说明 |
|------|------|
| **AI 讲解** | 针对左页选中或全文。正文语言由 **讲解语言** 决定 |
| **AI 翻译** | **逐字翻译** 或 **整段翻译**，可编辑，可开 **翻译对照** |
| **原文补充** | 根据节选识别名著，补全为风格一致的完整篇章 |
| **语音朗读** | 原文、讲解、翻译均可朗读，支持本地与在线神经女声 |
| **沉浸阅读** | 全屏双页/单页，仿真翻书动画，无 AI 界面干扰 |
| **目录书库** | 记住多个文件夹，快速打开原文、翻译或讲解文稿 |
| **自我进化** | （高级）AI 分析应用源码、排队优化项并自动改码升级 |

### 1.2 界面隐喻

整体 UI 采用「**翻开的书**」视觉：皮革封面、纸张纹理、书脊丝带、页码装饰。默认浅色书桌风格，可在 book 设置中切换预设主题。

### 1.3 两种顶层模式

| 模式 | 何时使用 |
|------|----------|
| **学习模式** | 需要 AI 讲解、翻译、朗读、编辑文稿 |
| **阅读模式** | 只想连续读正文，像读实体书一样翻页 |

二者可随时切换，**阅读进度**（spread 索引）按文件单独记忆。

## 2. 主窗口结构（学习模式）

```
┌─────────────────────────────────────────────────────────────┐
│ 顶栏：品牌 · 文件名 · 状态胶囊 · 大模型/Cursor · 播控        │
│ 工具栏：原文操作 | 讲解操作 | 翻译操作 | 朗读功能 | 进化       │
├──────────────────────────┬──────────────────────────────────┤
│  — 左页 —                 │  — 右页 —                         │
│  可编辑原文               │  Tab：读书助手 | AI进化             │
│  （或命令笔记）           │  · 讲解结果 / 翻译结果 分栏         │
│                           │  · 对话流、输入框、翻译工具条       │
└──────────────────────────┴──────────────────────────────────┘
```

- **默认窗口**：约 1280×860，最小约 960×640。
- **顶栏胶囊**：当前文件名、**未保存**。读书时显示当前模型名，未配好则显示 **book 未配置**；进化时显示 Cursor 模型名，未就绪则显示 **Cursor 未就绪**。顶栏没有「大模型 / Cursor」切换。
- **右页 Tab**：
  - **读书助手**：讲解对话 + 翻译区（两套内容独立）。
  - **AI 进化**：优化队列、Agent 执行过程、进化命令管理。

### 2.1 学习模式布局切换

| 布局 | 操作 |
|------|------|
| **双页** | ⌘⌥1。左原文 + 右 AI 并排 |
| **原文全屏** | ⌘⌥2。仅左页占满，便于编辑长文 |
| **右全屏** | ⌘⌥3。仅右页占满，便于阅读长讲解或翻译 |
| 恢复 | **Esc**，或再选 **双页** |

### 2.2 读书助手右页分栏

在「读书助手」Tab 内，右页再分为：

| 按钮 | 内容 |
|------|------|
| **讲解** | 多轮讲解对话、流式输出、可保存/打开/清空 |
| **翻译** | 翻译 JSON 或 **翻译对照**，可编辑，可 **对齐翻译** / **锁定翻译** |

按钮文案就是 **讲解** 和 **翻译**。悬停分别是「切换到右页讲解结果分栏」「切换到右页翻译结果分栏」。执行翻译类操作时会自动切到 **翻译**。已有内容用菜单 **显示讲解**、**显示翻译** 切换，不重新请求模型。

### 2.3 专注与界面精简

翻译/讲解区可以收起工具条和输入框，只留正文。恢复用 **专注阅读**、**显示工具栏**、**显示输入**。

## 3. 阅读模式（沉浸翻书）

### 3.1 进入与退出

| 操作 | 说明 |
|------|------|
| 进入 | 顶栏 **「阅读模式」**，快捷键 **⌘⇧P**（需已打开非空正文） |
| 退出 | 顶栏 **「学习模式」** 或 **Esc** |

阅读模式下**不提供** AI 讲解与翻译；需要 AI 时请先返回学习模式。

### 3.2 布局

| 选项 | 说明 |
|------|------|
| **双页** | 左第 N 页、右第 N+1 页，中间 **书脊固定不动** |
| **全屏** | 单页占满窗口 |
| 切换 | 阅读顶栏 **双页 / 全屏**，或 **⌘⌥1 / ⌘⌥2** |

### 3.3 翻页方式

| 方式 | 行为 |
|------|------|
| **← / →** | 上一跨页 / 下一跨页 |
| **点击左页 / 右页** | 向后 / 向前翻（双页布局下） |
| **水平滑动** | 跟手翻页；超过约三分之一松手则翻完，否则回弹 |
| **顶栏箭头** | 与键盘等效 |

翻页动画为 **单张纸页** 自然卷曲，书脊不参与变形，避免「撕书」感。

### 3.4 分页与进度

- 分页依据与左页相同的 **字号、字体、行距、页边距**（book 设置 → 外观风格）。
- 窗口大小或排版变化时会 **重新分页**，并尽量保持当前阅读位置。
- 每个文件的 **spread 索引** 会保存；再次进入阅读模式时恢复上次位置。
- 页脚显示类似：**第 3–4 页 / 共 128 页**（双页）或 **第 N 页 / 共 M 页**（全屏）。

## 4. 文稿与文件管理

### 4.1 支持的文稿类型

- 主要支持 **UTF-8 纯文本 `.txt`**。
- 左页全文可 **自由编辑**；支持选中、复制、拖拽打开文件。

### 4.2 文件菜单与原文操作

| 菜单上的名字 | 快捷键 | 说明 |
|------|--------|------|
| **原文新建** | ⌘N | 清空并新建左页文档 |
| **原文打开…** | ⌘O | 选择本地 `.txt`。工具栏同一动作是 **原文打开** |
| **原文打开目录…** | | 打开目录浏览（见 4.4）。工具栏是 **原文打开目录** |
| **原文保存** | ⌘S | 保存到当前文件路径 |
| **原文另存为…** | ⌘⇧S | 左页全文存为新文件 |
| **原文保存为 AIBook…** | | 原文和已有各语言译文、讲解存成一个 `.aibook` |
| **原文导出选中…** | ⌘⌥S | 仅导出左页当前选区 |
| **原文全选** | ⌘⌃A | |
| **原文补充** | ⌘⇧C | 见第 9 节 |

未打开外部文件时，左页加载 **命令笔记**（见 4.3）。

### 4.3 命令笔记（默认左页）

- 首次使用或无打开文件时，左页显示命令笔记，用于记录说明或历史进化相关文本。
- 保存位置：`~/Library/Application Support/AIBook/readme-notes.txt`
- 若无本地副本，会回退到应用内置或项目中的 `readme.txt` 模板。
- **⌘S** 保存命令笔记到 Application Support。

> 当前版本的 **优化队列** 以 `optimization-queue.json` 为主；命令笔记不再作为进化运行时命令源，但可作个人备忘。

### 4.4 目录浏览（书库）

**入口**：菜单 **原文打开目录…**。窗口标题是 **目录浏览**。

| 步骤 | 说明 |
|------|------|
| 添加目录 | 侧边栏 **+**，选择书籍根文件夹 |
| 切换目录 | 在 **已打开目录** 列表中点选 |
| 浏览文件 | 中间树形展开子文件夹 |
| 选择打开目标 | **在左页原文区打开**、**在右页翻译区打开**、**在右页讲解区打开** |
| 打开 | 双击或底部确认 |

已添加的目录与展开状态会 **持久化**，下次启动仍可用。适合在同一书库的多本 `.txt`、`-翻译.txt`、讲解稿之间切换。

## 5. AI 后端与配置

讲解、翻译、原文补充共用 **book 设置** 里的读书大模型。AI 进化固定使用 Cursor，在 **进化设置** 里配置，不从顶栏切换。

### 5.1 读书用大模型，进化用 Cursor

| 用途 | 界面入口 |
|------|----------|
| 讲解、翻译、原文补充 | **book 设置** → **AI模型设置** → **当前提供商** |
| 分析优化、进化 | **进化设置** 里的 **Cursor 模型**，以及 Cursor API Key、cursor-bridge |

未配好读书模型时，顶栏胶囊显示 **book 未配置**，相关按钮会提示先打开 **book 设置**。Cursor 未就绪时，胶囊显示 **Cursor 未就绪**。

### 5.2 book 设置（读书助手）

**入口**：顶栏 **book 设置** 按钮。

#### AI 模型设置

- 下拉 **当前提供商**。按提供商分别保存 API 地址、Key、默认模型。
- 内置提供商示例：

| 提供商 | 典型用途 |
|--------|----------|
| OpenAI | 云端 GPT 系列 |
| DeepSeek | 高性价比中文 |
| Ollama | **本机免费**（推荐日常读书） |
| Moonshot / 通义 / 智谱 | 国内云端 |
| 自定义 | 任意 OpenAI 兼容端点 |

**Ollama 快速开始**：

```bash
ollama serve
ollama pull llama3.2
```

在 book 设置中选择 Ollama，可 **扫描本机已安装模型** 并选用。若 Ollama 启用了 API Key，请在设置中填写。

- **翻译目标语言**、**讲解语言**：可多选简体中文、英语、日语、德语、法语、意大利语、拉丁语或希腊语。下次生成按勾选顺序逐个产出，已有内容可在右页切换，保存 `.aibook` 时一并保留。
- **左页节选占比**：控制每次请求带入的左页原文节选比例（避免超出模型窗口）。

#### 语音设置

见第 8 节。

#### 外观风格

见第 11 节。

### 5.3 进化设置

**入口**：菜单 **AIBook → 设置**（进化 Tab）。

| 配置项 | 说明 |
|--------|------|
| Cursor API Key | 或环境变量 `CURSOR_API_KEY` |
| **Cursor 模型** | 如 Composer 系列 |
| cursor-bridge 路径 | 项目内 `cursor-bridge` 目录 |
| **自动升级** | 一次点击 **进化** 后，若队列仍有待办，可连续执行（见第 10 节） |

**Cursor 本地依赖**：

```bash
cd ai-book/cursor-bridge
npm install
```

需 **Node.js 18+**。

## 6. 讲解功能（读书助手 · 讲解结果）

### 6.1 基本流程

1. 在左页 **选中** 一段文字（或不选，使用全文上下文）。
2. 点击 **「选择讲解」**（⌘R）或 **「全文讲解」**（⌘⇧R），或顶栏 **讲解操作** 菜单。
3. AI 按讲解语言逐个输出到右页「讲解结果」分栏。多种语言时弹出层标题带语言名和序号。
4. 讲解完成后，默认可 **自动朗读** 最后一种成功的讲解（可在流程中停止；语音见第 8 节）。

讲解正文使用所选讲解语言。目标为简体中文时，古文讲解用现代白话文。右页同一时间只显示一种语言；工具条「显示讲解」和讲解菜单可在已有讲解之间切换，不重新请求模型。打开或保存 `.aibook` 时，各语言讲解都保留。打开一份讲解 `.txt` 时，写入当前正在看的那种语言，其它语言不动。新建或清空只去掉当前这一种。

### 6.2 多轮追问

- 右页底部 **输入框** 可继续提问，AI 会结合当前文件与历史对话回答。
- 同一本书的对话会在重启后 **尽量恢复**（按文件路径关联会话存储）。

### 6.3 讲解文稿管理（讲解操作菜单）

| 操作 | 说明 |
|------|------|
| **新建讲解** | 清空当前这一种语言的讲解，其它语言留在包里 |
| **打开讲解** | 从 `.txt` 载入讲解稿，写入当前正在看的语言 |
| **保存讲解** | 将当前讲解保存为 UTF-8 文本 |
| **全选讲解** | 选中讲解区全部文字 |
| **清空讲解** | 删除当前这一种语言的讲解 |
| **朗读讲解** | 朗读讲解全文。朗读中同一项变为 **停止朗读讲解** |

### 6.4 单条消息操作

在讲解对话气泡上 **右键**，可复制、删除单条消息，或对单条 AI 回复点 **朗读此条**。

### 6.5 与选区的关系

点击顶栏按钮时，系统可能短暂清除左页高亮；应用会 **缓存最近一次非空选区**，保证「选择讲解」仍针对您刚才选中的文字。

## 7. 翻译功能（读书助手 · 翻译结果）

### 7.1 两种翻译模式

| 模式 | 入口 | 输出特点 |
|------|------|----------|
| **逐字翻译** | 翻译操作 → 逐字翻译 | 按原文顺序拆解字/词，附简短说明，适合精读、词汇对照 |
| **整段翻译** | 翻译操作 → 整段翻译 | 保留段落结构，通顺完整，适合章节阅读 |

**翻译源文本**：优先左页 **当前选中**；无选中则使用左页 **全文**。

**翻译目标语言**：可在 **book 设置 → AI模型设置 → 翻译目标语言** 中多选，也可从 **翻译操作** 菜单勾选。生成时按菜单顺序逐个翻译。右页同一时间只显示一种，已有译文可以用 **显示翻译** 切换。保存 `.aibook` 时各语言一起保留。中国古文以简体中文为目标时会翻译成现代简体白话文。

生成结果为结构化 **JSON**（内含对齐块），在右页翻译区展示；您可 **直接编辑** 文本或表格。

### 7.2 翻译文件管理

| 操作 | 说明 |
|------|------|
| 打开翻译 | 载入已有翻译 JSON/文本 |
| 保存翻译 | 常见命名：`原文件名-翻译.txt` |
| 清空翻译 | 删除当前翻译内容与对齐 |
| 全选翻译 | ⌘⌃⇧A |
| **朗读翻译** | 工具条和 **翻译操作** 菜单上的名字。菜单里的 **朗读翻译全文** 是 ⌘⌥T |

### 7.3 翻译对照与对齐

当翻译 JSON 包含有效对齐块（字/词/段）时，翻译工具条上的控件是：

| 界面文案 | 说明 |
|----------|------|
| **翻译对照** | 开关。悬停文案也是这四个字。打开后右页是原文–译文对照表 |
| **对齐翻译** | 左页正文变更后，重新计算与译文的对齐 |
| **锁定翻译** | 防止误触整体对齐；单行编辑通常仍可用 |
| **解锁翻译** | 恢复可整体对齐 |

讲解工具条是另一套同结构的按钮：**讲解对照**、**对齐讲解**、**锁定讲解**、**解锁讲解**。

左页改动较大时，工具条提示原文是：**对齐已失效，点击「对齐翻译」或「对齐讲解」恢复**。

### 7.4 与左页滚动的联动

在学习模式 **双页** 布局下，打开 **翻译对照** 且对齐有效时，左页滚动可与对照表联动高亮当前段落/块。

## 8. 语音朗读

### 8.1 朗读入口汇总

| 对象 | 菜单上的名字 |
|------|----------------|
| 左页选中 | **朗读功能** → **原文朗读选中**。⌘⌥R 对应 **原文朗读（选中/全文）** |
| 左页全文 | **朗读功能** → **原文朗读全文** |
| 翻译 | 工具条和 **翻译操作** 是 **朗读翻译**；⌘⌥T 是 **朗读翻译全文** |
| 讲解 | **讲解操作** → **朗读讲解**；气泡右键是 **朗读此条** |
| 试听 | **book 设置** → **语音设置** |

### 8.2 顶栏播控

朗读进行中时，顶栏中部是 **暂停**、**继续**、**停止**。

### 8.3 朗读节奏（book 设置 → 语音设置）

分段控件的标题是 **朗读节奏**。选项和控件下方的说明是：

| 选项 | 界面说明 |
|------|----------|
| **快速** | 快速：语速较快，适合浏览式收听。 |
| **平衡** | 平衡：语速与停顿适中，推荐默认。 |
| **自然** | 自然：略慢、咬字更清晰，适合讲解。 |
| **舒缓** | 舒缓：语速较慢、停顿更长，适合细读。 |

### 8.4 语言处理

分段控件的标题是 **语言处理**。选项：

| 选项 | 界面说明 |
|------|----------|
| **高效** | 语言处理 · 高效：更少改写，切句更长，适合追求速度。 |
| **平衡** | 语言处理 · 平衡：速度与表达清晰度均衡，推荐默认。 |
| **深度** | 语言处理 · 深度：更短分句、标点停顿、缩写拆读与可读化，减少吞字和长句含混。 |

### 8.5 讲解声音

声音下拉的标题是 **讲解声音**。

- **系统中文语音**：使用 macOS 内置中文声音。
- **在线神经女声**（Edge TTS）：如晓伊、晓晓及多种方言/地区女声。
- 在线声音需先在设置中 **下载样本** 到本地缓存目录后方可稳定使用。

朗读前会对 Markdown 等做 **清洗与分句**，以提升听感。

### 8.6 语音操作

顶栏麦克风 **按住说话、松开执行**。阅读模式里没有这颗按钮时，在应用前台 **按住 Option+空格** 同样有效。软件先把语音转成文字，再用翻译和讲解同一套读书大模型解析成已有功能：讲解、翻译、朗读、布局、打开、保存、导出等会马上执行。开始进化和分析优化会先确认。没听清，或这句话对不上任何功能时，不执行，只显示听到的文字。

## 10. AI 进化（高级功能）

> **警告**：进化会修改 AIBook 源码并重新安装应用。请在了解 Git/备份的前提下使用，不建议在重要环境盲目打开 **自动升级**。

### 10.1 做什么

- **分析优化**：AI **只读** 浏览项目，提出可改进项，写入 **优化队列**（不改代码）。
- **进化**：从队列取一条 **待办**，AI **改代码** → 构建安装 → **重启应用**。

### 10.2 典型流程

1. 切换到右页 **AI 进化** Tab。
2. 点击 **「分析优化」**，等待 Agent 输出建议并入队。
3. 查看队列中的条目（标题、编号、状态）。
4. 点击顶栏 **进化**（菜单里同一快捷键挂在 **自我进化** 上，⌘E）执行下一条待办。
5. 观察思考过程与工具步骤时间线。
6. 完成后应用可能自动重启；若打开 **自动升级**，且本次会话已经手动点过 **进化**，后续待办可能连续执行。

### 10.3 进化命令与队列文件

- 队列文件：`~/Library/Application Support/AIBook/optimization-queue.json`
- 进化菜单里是 **保存进化命令**、**打开进化命令**。
- 分析入队时会 **去重**（标题规范化匹配）；单次分析建议条目数有上限（约 8 条）。

### 10.4 执行通道

**分析优化** 和 **进化** 都走 Cursor 本地 Agent，没有「改用大模型」的开关。分析只读源码；**进化** 才改代码、构建并安装。Cursor 未就绪时按钮不可用，顶栏显示 **Cursor 未就绪**。

### 10.5 Token 与状态

- 进化与长对话受 **Token 预算** 限制，界面会显示用量；超限将阻止发送。
- 顶栏胶囊可显示 **待办条数**、下一条编号等状态。

## 16. 推荐使用场景

### 16.1 日常读书 + 答疑

1. ⌘O 打开章节 `.txt`。  
2. 选中不懂的段落 → ⌘R 讲解。  
3. 底部输入框追问。  
4. 需要专注阅读时 → ⌘⇧P 进入阅读模式。

### 16.2 外语 / 经典精读

1. 左页载入原文。  
2. **整段翻译** 或 **逐字翻译**。  
3. 打开 **翻译对照**，需要稳住时点 **锁定翻译**。  
4. ⌘⌥T 朗读译文，⌘⌥R 朗读原文对比。

### 16.3 多文件书库

1. **文件 → 打开目录…** 添加书库根目录。  
2. 树中选择 `chapter-01.txt` → 打开到 **原文**。  
3. 选择 `chapter-01-翻译.txt` → 打开到 **翻译**。  
4. 在同一窗口切换讲解与翻译分栏。

### 16.4 节选补全

1. 左页粘贴教材节选。  
2. ⌘⇧C **原文补充**。  
3. 检查补全结果后 ⌘S 保存。

## 17. 常见问题

**Q：点击讲解提示未配置大模型？**  
A：打开 **book 设置 → AI 模型设置**，选择提供商并填写 API Key；本机推荐 Ollama。

**Q：Cursor 本地不可用？**  
A：检查 Node.js、cursor-bridge 的 `npm install`、Cursor API Key 与进化设置中的路径。

**Q：翻译对照是灰的？**  
A：需先完成 **逐字翻译** 或 **整段翻译**，且 JSON 含有效对齐块。失效时点 **对齐翻译**。

**Q：阅读模式页码变了？**  
A：更改字号或窗口大小会重新分页；属正常现象，进度仍按 spread 尽量恢复。

**Q：进化后应用行为变了？**  
A：进化修改的是本地安装的 AIBook 副本；请用 Git 管理源码，并谨慎打开 **自动升级**。

**Q：说明书与界面不一致？**  
A：以您安装的 **AIBook 版本** 为准；悬停按钮查看最新 hint。
