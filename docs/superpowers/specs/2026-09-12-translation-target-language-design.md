# 可配置翻译目标语言设计

## 背景

当前翻译提示词使用固定中文描述，未将应用界面语言与译文目标语言分离。用户需要把中国古文等原文翻译成现代简体中文、英语、日语、希腊语等语言，并能独立设置翻译目标语言。

## 目标

- 翻译目标语言独立于应用界面语言。
- 默认跟随当前应用界面语言。
- 支持简体中文、英语、日语、德语、法语、意大利语、拉丁语和希腊语。
- 在阅读设置和翻译操作菜单中使用同一个目标语言设置。
- 切换目标语言仅影响之后发起的翻译，不修改或清空已有译文。
- 简体中文目标明确支持把中国古文翻译成现代简体白话文。

## 非目标

- 不要求用户设置原文语言；由翻译模型根据原文判断。
- 不在切换目标语言时自动重译当前内容。
- 不支持用户输入任意语言名称。
- 不改变现有译文文件格式或翻译对齐数据结构。

## 数据模型与持久化

新增独立的 `TranslationTargetLanguage` 类型，包含：

- `followAppLanguage`
- `zhHans`
- `en`
- `ja`
- `de`
- `fr`
- `it`
- `la`
- `el`

`AppSettings` 新增可发布属性 `translationTargetLanguage`，通过 `UserDefaults` 持久化。旧版本没有保存值，或保存值无法解析时，均回退到 `followAppLanguage`。

`followAppLanguage` 在每次发起翻译时动态解析，而不是在用户选择时复制语言值：

1. 应用选择了具体界面语言时，使用该语言。
2. 应用选择“系统”时，根据 macOS 当前区域语言匹配八种受支持语言。
3. 系统语言不在支持范围内时回退到英语，与现有界面国际化策略一致。

## 界面设计

### 翻译操作菜单

在菜单顶部增加“目标语言”子菜单：

- 显示“跟随界面语言”和八种具体语言。
- 当前选项带勾选状态。
- 选择后立即持久化，但不触发翻译，也不改变已有译文。

### 阅读设置

在“阅读设置 → AI”中增加“翻译目标语言”选择器和简短说明。该选择器与翻译操作菜单绑定同一个 `AppSettings.translationTargetLanguage`。

所有标题、选项和说明文案均通过现有 String Catalog 国际化，并覆盖八种界面语言。

## 翻译数据流

1. 用户选择逐字翻译或整段翻译。
2. `ReadingViewModel` 从 `AppSettings` 取得目标语言设置。
3. 若设置为跟随界面语言，则在此时解析为具体语言。
4. `ReadingViewModel` 将具体目标语言传给 `TranslationPromptBuilder`。
5. 提示词明确要求所有 `translation`、`translationText`、`summary`、`hardPoints` 和注释内容使用目标语言，同时保持 JSON 字段名和现有结构不变。
6. 模型响应继续进入现有解析、对齐和展示流程。

逐字翻译与整段翻译必须使用相同的目标语言解析逻辑。用户提供的附加翻译要求仍可调整风格和细节，但不能使系统遗漏明确的目标语言约束。

## 提示词规则

每种目标语言使用稳定、明确的语言名称和 BCP-47 标识构造提示词，避免仅依赖当前界面文案。

简体中文目标增加专门规则：

- 输出使用现代简体中文。
- 原文若为中国古文、文言文或古典汉语，应翻译成通顺准确的现代白话文。
- 保留必要的古文词义说明，但不得把原文简单改写为繁体或原样复制。

其他目标语言明确要求把原文翻译为对应语言。提示词自身可以继续使用中文，但目标语言约束必须与界面语言无关。

## 错误与兼容处理

- 缺失或损坏的持久化值回退到“跟随界面语言”。
- 无法识别的系统语言回退到英语。
- 目标语言解析不引入新的运行时失败路径。
- 现有译文不携带新的强制元数据，因此打开旧译文的行为保持不变。
- 切换目标语言后，保存、打开、朗读及本地重新对齐已有译文均保持原行为。

## 测试

新增或扩展单元测试以覆盖：

- 所有枚举值的持久化原始值稳定。
- 缺失值和非法值迁移为 `followAppLanguage`。
- 跟随具体界面语言时解析正确。
- 跟随系统语言时，八种语言匹配正确，不支持的语言回退英语。
- 八种具体目标语言均正确进入翻译提示词。
- 简体中文提示词包含古文转现代简体白话文约束。
- 逐字和整段模式均包含目标语言约束，且保留原 JSON 结构。
- 修改目标语言设置不会修改、清空或自动重新生成已有译文。
- 新增的 String Catalog 键在八种界面语言中完整存在。

## 验收标准

- 用户可在阅读设置和翻译操作菜单中选择相同的目标语言设置。
- 首次使用时默认显示“跟随界面语言”。
- 选择具体语言后，下一次逐字或整段翻译使用该语言。
- 选择“跟随界面语言”后，下一次翻译使用当时生效的界面语言。
- 中国古文以简体中文为目标时，输出为现代简体白话文。
- 切换设置不会改变当前已经生成的译文。
