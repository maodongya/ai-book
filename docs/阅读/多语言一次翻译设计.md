# 多语言一次翻译

译文目标语言可以多选。点「逐词翻译」或「整段翻译」时，按菜单顺序逐个生成所选语言。每种语言写入当前文档的语言包，保存 `.aibook` 时一并落盘。右页同一时间只显示一种语言。

## 选择

可选语言是八种具体语言：`zh-Hans`、`en`、`ja`、`de`、`fr`、`it`、`la`、`el`。至少保留一种。

「跟随界面语言」不再出现在多选里。旧的单选如果是跟随界面语言，第一次读取时收成当时的界面语言，并只勾这一种。

勾选决定下次翻译要生成哪些语言，不删除已经生成的译文。菜单和设置页都是多选框，可以连续勾选或取消多种，点一次不会关掉菜单。只剩一种时不能再取消。取消勾选不删除已经生成的译文。要看哪一种，用「显示译文」。

当前显示的语言单独记住。它可以暂时不在勾选集合里，直到下一次翻译结束，右页停在最后一种成功的语言上。

## 切换已有译文

右页译文工具条在至少有一种译文时显示「显示译文」菜单，列出语言包里已有译文的语言。当前正在看的译文若还没写入语言包，先按当前显示语言记入，因此已有的中文译文也会出现在菜单里。

选择另一种语言时，先把右页当前译文写回它自己的语言，再装入所选语言的正文和对齐。不重新请求模型，也不改「下次要翻译哪些语言」的勾选。只有一种译文时，菜单显示该语言名称，不能切换。

## 生成

一次只跑一种语言，一种完成后再请求下一种。整段翻译每种语言内部仍按段分批，并用原来的严格段验收。验收失败的语言不写入语言包，队列继续下一种。网络失败或用户停止时，已写入的语言保留，未开始的语言不再请求。

进度弹窗在整次翻译期间保持打开。多种语言时标题带语言名和序号，例如「日语（2/3）· 正在翻译第 1–10 段（共 20 段）」。

每种语言开始前，右页先换成这种语言已有的译文（没有则为空），避免上一种语言的正文被当成这一种的旧译。成功后把右页正文和对齐写入 `bundledLanguages[语言码]`。

## 保存与打开

`.aibook` 仍按语言目录存放译文。本次生成的语言和包里原有的其它语言一起保存。打开后，右页显示当前记住的那种语言；改当前显示语言时，从已装入的语言包切换，不重新请求。
