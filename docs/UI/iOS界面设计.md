# AIBook iOS 界面设计

> 文档性质：iPhone 与 iPad 的界面设计。不改 macOS 窗口。  
> Mac 见 [Mac界面设计.md](./Mac界面设计.md)。  
> 本文只定界面，不改 `ContentView` 或 Mac 书页。

iOS 和 Mac 读的是同一类书：原文、讲解、翻译、朗读、语音操作、原文补充和 `.aibook`。手机上不能把 Mac 的书桌缩进来。Mac 是左右同时摊开；iOS 一次把一件事铺满屏幕，需要对照时再进入对照，而不是永远挤出半页书脊。

---

## 1. 原则

| 原则 | iOS 上的做法 |
|------|----------------|
| **一次一件事** | iPhone 默认只显示原文、讲解、翻译、阅读四者之一。 |
| **书页留在内容上** | 纸色、墨色、字号和字体跟 Mac 的主题走。皮革顶栏、书桌和书脊不作为 iPhone 的默认外壳。 |
| **主操作用大按钮** | 讲解、翻译、朗读放在当前页的底栏或页内主按钮上，不排成 Mac 那条两栏工具条。 |
| **系统界面用系统的** | 打开文件用系统文件选择器，设置用表单页，长文用系统分享和返回栈。 |
| **不改 Mac** | iOS 导航、安全区和横竖屏只写在 iOS 界面里。 |

iPad 宽屏可以并排看原文和助手，那是 iPad 的宽布局，不是把 Mac 窗口搬过来。窄于并排宽度时，iPad 与 iPhone 使用同一套单页。

---

## 2. 信息架构

底部四项，iPhone 始终可见。进入沉浸阅读后底栏隐藏，退出阅读再回来。

| 底栏 | 这一页负责 |
|------|------------|
| **原文** | 打开、编辑、选中、保存、目录、原文补充。 |
| **讲解** | 选择讲解、全文讲解、追问、切换已生成的讲解语言。 |
| **翻译** | 逐字翻译、整段翻译、对照、对齐和锁定。 |
| **阅读** | 按页翻正文。没有助手。 |

右上角两个固定入口，四个底栏页都有：

| 入口 | 作用 |
|------|------|
| **麦克风** | 按住说话，松开执行。和 Mac 同一套口令，不改模型、主题或语言勾选。 |
| **更多** | book 设置、说明书、隐私政策、保存为 `.aibook`。 |

未保存时，原文页标题旁显示一个小点，不在底栏上再做一个保存页。

```
iPhone 竖屏
┌──────────────────────────┐
│                          │
│ 原文                      │
│ 翻译                      │
│ 讲解                      │
│ 设置                      │
│                          │
│                          │
│                          │
│                          │
│                          │
│                          │
└──────────────────────────┘

iPhone 横屏
┌──────────────────────────┐
│                          │
│ 原文                      │
│ 翻译                      │
│ 讲解                      │
│ 设置                      │
│                          │
└──────────────────────────┘
左边换页按钮与右上角「更多」同一格式：墨色圆圈图标，点开是系统下拉，条目为原文、翻译、讲解、book 设置。不使用浅蓝半圆气泡。book 设置对齐 Mac：界面语言八种、风格预设与阅读字体/字号共用偏好；纸色与墨色跟 `BookStyleManager` 令牌，切预设后全应用重绘。
```

阅读页隐藏底栏后，只留正文、页码，以及一条轻触出现的顶边：返回、双页或单页、麦克风。

## 3. 原文页

标题是当前文件名。没有打开文件时，页中是两枚主按钮：**打开文本**、**打开目录**。打开目录沿用已记住的文件夹；系统允许时用安全范围书签，不在 iOS 上另做一套书库逻辑。

正文可编辑。选中文字后，选区上方浮出三条：

| 动作 | 结果 |
|------|------|
| **讲解** | 切到讲解页，并开始选择讲解。 |
| **翻译** | 切到翻译页。下一次翻译用这段选区。 |
| **朗读** | 就地朗读选区，不离开原文页。 |

页底工具条只留原文自己的事：保存、另存、原文补充、全选。讲解和翻译的主按钮不放在这里，避免和底栏重复。

拖放和文件 App 分享进来的 `.txt` 进左页原文；`.aibook` 打开后原文、各语言译文和讲解一起恢复，仍停在原文页。

---

## 4. 讲解页

上半是讲解正文，下半是追问输入。键盘弹起时输入条贴在键盘上，底栏让开。

页顶一条分段：**讲解语言**里已经生成的那些语言。切换只改显示，不重新请求。还没有讲解时，分段不出现，页中是空状态和两枚按钮：

| 按钮 | 作用 |
|------|------|
| **讲解选区** | 用原文页最近一次非空选区。没有选区时按钮不可用，并写明先回原文选中。 |
| **全文讲解** | 用整篇原文。原文为空时不可用。 |

生成时按 book 设置里勾选的讲解语言顺序逐个写出。多种语言时，进度写在页顶：语言名和序号。完成后可以自动朗读最后一种，页顶出现暂停和停止。

讲解稿的新建、打开、保存、清空放在页内「⋯」里，不占主按钮。讲解对照是这一页的一种显示：打开后原文块和讲解块上下叠放，点一块就看见对应的原文。iPhone 不用左右分栏做对照。

锁定讲解、对齐讲解与 Mac 同一含义：原文改多了，页顶提示对齐已失效。

---

## 5. 翻译页

结构和讲解页对称。空状态两枚按钮是 **逐字翻译** 和 **整段翻译**。源文本优先用原文选区，没有选区就用全文。

页顶分段切换已经生成的译文语言。正文默认可编辑。打开 **翻译对照** 后，每一块是上原文、下译文，当前块随原文阅读位置高亮。锁定翻译后，整表不再重排，单块仍可改字。

打开译文、保存译文、清空、对齐、锁定放在页内「⋯」。保存名沿用「原文件名-翻译」。

---

## 6. 阅读页

这是 iOS 上的沉浸阅读，对应 Mac 的阅读模式，但手势按手机来。

| 姿态 | 页面 |
|------|------|
| iPhone 竖屏 | 单页。点右侧下一页，点左侧上一页。左右滑动作相同。 |
| iPhone 横屏、iPad | 可以双页。中间留一条窄缝，不画 Mac 那条装饰书脊。 |
| 翻页反馈 | 跟手滑动。超过约三分之一松手翻完，否则回到本页。 |

分页使用当前字号、字体、行距和页边距。旋转或改字号后重排，并尽量留在刚才的字附近。每份文件记住读到哪里。页脚只留「第 N 页 / 共 M 页」。

阅读页不提供讲解和翻译。要问模型，点返回，回到进入阅读前的那一页。

---

## 7. iPad 宽屏

宽度足够时，原文可以和讲解或翻译并排。并排不是 Mac 窗口：

- 左边约一半是原文，右边约一半是当前助手。右边用分段在讲解和翻译之间切换。
- 没有皮革顶栏，没有十二个装订孔的书脊。中间是分隔线。
- 底栏仍然在：原文、讲解、翻译、阅读。点讲解或翻译时，若已经并排，只切换右半，不把左半原文卸掉。
- 宽度不够并排时，立刻回到第 2 节的单页，不留一个被压扁的双页。
- 阅读页在 iPad 上默认双页，用户可以改成单页。这个选择记在本机，不影响 Mac。

## 8. 设置、说明书和隐私

从「更多」推进一个表单页，分组与 Mac 的 book 设置相同，控件用 iOS 的列表：

| 组 | 内容 |
|----|------|
| **模型** | 当前提供商、地址、密钥、模型、讲解语言、翻译语言、左页节选占比。 |
| **语音** | 朗读节奏、语言处理、讲解声音。在线声音先下载再选用。 |
| **外观** | 界面语言、主题、字号、字体。装饰开关里，书脊丝带和折页角在 iPhone 单页上不显示；字号和字体对原文、讲解、翻译、阅读都生效。 |

说明书和隐私政策各是一页可滚动文本，语言跟界面语言走。隐私页在有公开网址时，顶部放该链接。

模型未配置时，讲解页和翻译页的主按钮打开模型设置，不先发一次失败请求。

---

## 9. 语音和朗读

麦克风在导航右上角。按住时页面不跳转，松手后若口令对应另一个底栏页，再跳过去并执行。例如说「全文讲解」，停在讲解页并开始全文讲解。没听清，在麦克风下方短暂显示听到的文字。

正在朗读时，当前页顶部一条细条：来源（原文、讲解或译文）、暂停、停止。细条不替换底栏。阅读页的细条贴在临时顶边上。

系统语音可离线。在线声音需要网络，和 Mac 相同。

---

## 10. 和 Mac 的分界

两边共用：

- 原文、`.txt`、`.aibook`、目录书库、讲解、翻译、对照、对齐、锁定、朗读、语音口令、原文补充、八种界面语言、同一套模型设置。

两边不共用：

| Mac | iOS |
|-----|-----|
| 书桌、皮革顶栏、书脊、左右纸页同时摊开 | iPhone 单页；iPad 宽屏才并排，且没有书脊装饰 |
| 顶栏两栏工具条，窄了再溢出 | 底栏四个目的地，主按钮在当前页 |
| ⌘⌥1 / 2 / 3，Option+空格 | 点按、滑动、按住麦克风；外接键盘可以复用 Mac 快捷键，没有键盘时不依赖它们 |
| 阅读模式盖住整个窗口 | 阅读是底栏的一页，进入后隐藏底栏 |

做 iOS 界面时不修改 Mac 的窗口、顶栏分栏、书脊和阅读模式翻页。
