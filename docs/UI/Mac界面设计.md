# AIBook macOS 界面设计

> 文档性质：当前 macOS 窗口的界面设计。只描述 Mac，不规定 iPhone 或 iPad。  
> 对应实现：`Sources/AIBook/Reading/ContentView.swift` 及其调用的书页、工具栏和设置。  
> iOS 见 [iOS界面设计.md](./iOS界面设计.md)。  
> 较早的 [整体UI文档设计.md](./整体UI文档设计.md) 仍写着三栏工具栏、Cursor 和进化页，那些已不在当前 Mac 窗口里。以本文为准。

本文不改界面。它把已经在 Mac 上使用的窗口记下来，避免以后做 iOS 时回头改这套布局。

---

## 1. 窗口在做什么

Mac 把读书放在一张书桌上。窗口像一本摊开的书：上面一条皮革顶栏，下面左页原文、右页助手，中间书脊不动。

两种用法：

| 模式 | 窗口里看见什么 |
|------|----------------|
| **学习模式** | 左页可编辑原文，右页是讲解或翻译。顶栏放文件、讲解、翻译和朗读。 |
| **阅读模式** | 只留正文和翻页。助手、工具栏和输入框退出窗口。 |

默认窗口约 1280×860，最小约 960×640。标题栏隐藏，书名和文件名画在皮革顶栏里。外观保持浅色纸页。主题、字号和字体从 book 设置里换，换完左页立刻变，阅读模式按新排版重新分页。

## 2. 学习模式

### 2.1 整窗

```
┌──────────────────────────────────────────────────────────┐
│ 皮革顶栏                                                  │
│  书标 · AIBook · 模型胶囊 · 文件名 · 未保存 · 麦克风       │
│  语音状态行                                               │
│  左：读书助手 · 阅读模式 · book 设置 · 原文/讲解或翻译/朗读 │
│  右：讲解|翻译切换 · 当前栏的主按钮，或朗读中的暂停和停止   │
├────────────────────────────┬─────────────────────────────┤
│ 左页 原文                   │ 右页 讲解或翻译              │
│ 可编辑文本                  │ 对话、对照表、输入            │
│ 页脚：字数 · 选区 · 全选 · 保存状态                        │
└────────────────────────────┴─────────────────────────────┘
         中间是书脊，书脊不参与左右对调
```

左栏约占工具栏宽度的五分之二，右栏用剩下的宽度。窗口变窄时，按钮从完整文字收成少量按钮，再收进溢出菜单。朗读进行时，右栏换成来源、暂停和停止，不再放讲解或翻译主按钮。

### 2.2 三种学习布局

| 布局 | 怎么进入 | 窗口 |
|------|----------|------|
| **双页** | ⌘⌥1，或全屏顶上的「双页」 | 左原文 + 书脊 + 右助手 |
| **原文全屏** | ⌘⌥2 | 只留左页，顶上可回到双页 |
| **右全屏** | ⌘⌥3 | 只留右页，便于读长讲解或长译文 |

Esc 从左全屏或右全屏回到双页。这三种布局都还在学习模式里，右页助手没有卸掉。

### 2.3 顶栏左栏

从左到右，宽窗口时是：

| 按钮 | 作用 |
|------|------|
| **读书助手** | 回到右页助手。当前就在助手页时高亮。 |
| **阅读模式** | 原文非空且没有请求在跑时，进入沉浸翻书。快捷键 ⌘⇧P。 |
| **book 设置** | 打开设置：模型、语音、界面语言和外观。 |
| **原文操作** | 新建、打开、打开目录、保存、另存为、保存为 `.aibook`、导出选中、全选、原文补充。 |
| **讲解操作** 或 **翻译操作** | 跟着右页当前分栏出现。讲解栏是讲解稿的新建、打开、保存、清空和朗读；翻译栏是译文的打开、保存、清空、对齐和锁定。 |
| **朗读功能** | 原文、译文、讲解的选区或全文。 |

模型还没配好时，讲解、翻译和朗读先指向 book 设置，不发请求。

### 2.4 顶栏右栏

右页同一时间只显示一种结果：

| 按钮 | 作用 |
|------|------|
| **讲解** | 切到已有讲解，不重新请求。 |
| **翻译** | 切到已有译文。执行翻译时也会自动切到这里。 |
| **选择讲解** / **全文讲解** | 讲解栏的主按钮。选择讲解用最近一次非空选区。 |
| **逐字翻译** / **整段翻译** | 翻译栏的主按钮。有选区用选区，否则用全文。 |

多种讲解语言或译文语言已经生成时，在右页工具里切换，不在顶栏再排一排语言按钮。

### 2.5 左页

左页是可编辑的 UTF-8 文本，可以选中、复制，也可以把文件拖进来。空白且还没打开文件时，页中是打开文件的欢迎态。

页脚从左到右：页码装饰、字数、选区字数（有选区才出现）、全选、保存状态。未保存用橙色。

左页滚动在双页学习模式、并且翻译对照或讲解对照有效时，带动右页高亮当前块。

### 2.6 右页

右页纸色比左页略暖。页内是读书助手，不再有进化页。

讲解分栏：多轮对话、流式输出、底部输入框。气泡上可以复制、删除，或只朗读这一条。讲解对照、对齐讲解、锁定讲解在这一栏的工具里。

翻译分栏：可编辑的译文。对齐有效时可以打开翻译对照。对齐失效时提示重新对齐。锁定后不再整表重排。

长文可以把工具条和输入收起，只留正文。

## 3. 阅读模式

原文非空才能进入。进入后学习顶栏和右页助手离开窗口。

| 布局 | 看见什么 |
|------|----------|
| **双页** | 左第 N 页，右第 N+1 页，书脊固定。⌘⌥1。 |
| **全屏** | 单页铺满。⌘⌥2。 |

翻页：← / →、点左页或右页、水平滑动、顶栏箭头。滑过大约三分之一松手就翻完，否则弹回。动画是一页纸卷过去，书脊不变形。

分页使用当前字号、字体、行距和页边距。窗口或排版变了就重排，并尽量停在原来的跨页。每份文件记住自己的跨页。页脚写「第 3–4 页 / 共 128 页」或单页的「第 N 页 / 共 M 页」。

退出：顶栏回到学习模式，或 Esc，或再按 ⌘⇧P。退出后左页滚到刚才读到的位置。

阅读模式里没有麦克风按钮时，前台按住 Option+空格仍可语音操作。

## 4. 从窗口打开的其他 Mac 界面

这些是 Mac 上的独立窗口或表单，不嵌进书页左右栏。

| 界面 | 入口 | 内容 |
|------|------|------|
| **book 设置** | 顶栏 | 三栏：AI 模型、语音、外观。外观里有界面语言、主题、字号、字体和装饰开关。顶上可开说明书和隐私政策。 |
| **目录浏览** | 原文操作 | 已记住的文件夹、树、打开到左页原文或右页翻译或右页讲解。 |
| **功能说明书** | 帮助菜单、设置顶栏 | 跟界面语言走的说明书。 |
| **隐私政策** | 帮助菜单、设置顶栏 | 跟界面语言走的说明；有公开网址时显示链接。 |

菜单栏的文件和编辑命令与顶栏动作一致，不另做一套功能。

---

## 5. 语音在 Mac 窗口上的位置

麦克风在顶栏右侧，按住说话，松开执行。听写和执行状态独占顶栏里的一行，不挤进书名那一行。没听清就只显示听到的文字。正在理解时可以停止这一轮。

朗读中的暂停、继续、停止在顶栏右栏，不盖住书页。

---

## 6. Mac 界面不包含的东西

- 没有进化页，没有 Cursor 切换，工具栏不是左中右三栏。
- 不把 iPhone 的底栏、单页栈或 iPad 分栏写进这个窗口。
- 不因为做 iOS 去改双页比例、书脊、顶栏分栏或阅读模式翻页。

iOS 要用同一套读书能力时，走自己的导航，见 iOS 文档。两边可以共用文案、主题色和阅读数据，不共用这张书桌的布局。
