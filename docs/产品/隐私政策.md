# AIBook 隐私政策

AIBook 在你这台 Mac 上读书。原文、选中文字、追问，以及语音操作听写成的文字，只会在你点讲解、翻译、发送或松开语音键时离开本机。

接收方是你在 book 设置里选中的那一家。讲解菜单、翻译菜单和输入条上方会写明公司名和主机名。各家使用你自己的 API Key，Key 只存在本机。

麦克风只在你按住语音键时打开，用来把口令听成文字。系统能在本机识别时，音频不上传。听出的文字若要执行讲解或翻译，会发给上面写明的那一家。

书籍文件、API Key 和设置写在本机的 Application Support 与偏好设置里。AIBook 不用这些内容做跨 App 跟踪。

上架时把本页放到公开网址，填进 App Store Connect 的隐私政策栏，以及 `PrivacyPolicy.publicURL`。
