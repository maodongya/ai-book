# AIBook Privacy Policy

AIBook reads on this Mac. Source text, selections, follow-up questions, and words heard by voice control leave the Mac only when you explain, translate, send, or release the voice key.

The recipient is the provider you chose in Book Settings. The company and host are written in the explanation menu, the translation menu, and above the input. Each provider uses your own API key, stored only on this Mac.

The microphone turns on only while you hold the voice key, to turn a command into text. When the system recognizes speech on this Mac, the audio is not uploaded. Recognized words that run an explanation or translation go to the recipient named above.

Books, API keys, and settings stay in Application Support and preferences on this Mac. AIBook does not use them to track you across apps.

Before release, publish this page at a public address, enter that address in App Store Connect, and set `PrivacyPolicy.publicURL`.
